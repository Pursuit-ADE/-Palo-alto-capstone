# Source

Synthetic second dataset for PRD A7 (repeatable onboarding). Fictional company
**Northstar Hardware**. Not Maven, not Palo Alto Networks, and not real customer data.

Same column names as `data/maven-crm/` so the existing seed loader and the three
governed metrics can run after a human confirms the proposal. Dates are in the
same 2016–2017 window so the existing date shift still lands on the snapshot
date (2026-10-08).
